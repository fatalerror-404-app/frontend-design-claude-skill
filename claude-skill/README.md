# Frontend Design Skill

A practical design-direction skill for creating distinctive, intentional, and polished web interfaces with AI assistance.

This repository contains a reusable `SKILL.md` that guides an AI assistant through the visual-design process—from understanding the subject and audience to building a deliberate visual system, reviewing the design direction, and critically refining the final interface.

## What this skill does

The skill helps an AI assistant:

- Ground visual decisions in the product, subject matter, audience, and purpose.
- Choose a considered color palette, typography system, and layout direction.
- Avoid repetitive, generic, template-like AI design patterns.
- Plan the interface before writing code.
- Review the proposed direction against the brief and revise generic choices.
- Use restrained, purposeful visual hierarchy and motion.
- Write clear, user-focused interface copy.
- Keep accessibility and responsive behavior in view, including keyboard focus and reduced-motion preferences.

## Design workflow

1. **Understand the brief** — identify the product, audience, content, and primary user goal.
2. **Build a visual direction** — define color, typography, layout, alignment, and design principles.
3. **Challenge generic choices** — identify anything that feels like a default template and replace it with a brief-specific decision.
4. **Implement carefully** — write the interface while maintaining clear CSS structure and selector specificity.
5. **Review and refine** — critique the result, remove unnecessary decoration, and check responsive and accessibility fundamentals.

## How to use

1. Download or clone this repository.
2. Open `Claude skill/skill.md` and provide it to an AI assistant or agent that supports reusable skill/instruction files.
3. Give the assistant a clear design brief, including the product or subject, target audience, content, and intended user actions.
4. Ask it to follow the skill's planning, critique, implementation, and refinement workflow.

For the best results, provide real content and specific project context rather than asking for a generic landing page.

## Example prompt

> Use the instructions in `Claude skill/skill.md` as your design process. First understand the product, audience, and primary user goal. Propose a distinctive visual direction with a 4–6 color palette, typography, layout, alignment, and design principles. Critique the plan for generic AI-design patterns, revise it where needed, and only then implement a responsive, accessible interface.

## Core philosophy

**Design should come from the brief—not from a reusable visual formula.**

A strong interface has a clear point of view. Typography, color, layout, motion, and copy should each serve the product and its users. Use visual boldness deliberately, keep supporting elements disciplined, and remove decoration that does not improve meaning or usability.
